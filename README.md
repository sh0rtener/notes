# ShNotes

**ShNotes** — простой REST API для работы с заметками, разработанный на **ASP.NET Core**.

Проект построен с разделением ответственности между слоями приложения и ориентирован на создание поддерживаемой и расширяемой backend-архитектуры.

## Возможности

- Создание заметок
- Просмотр списка заметок
- Поиск заметок по названию
- Просмотр отдельной заметки
- Редактирование заметок
- Удаление заметок
- Хранение заметок в базе данных
- Работа с заметками через REST API
- Интерактивная документация API через Swagger

## Стек технологий

* **.NET 8**
* **ASP.NET Core Web API**

* **SQLite**

## Архитектура

Проект разделён на несколько слоёв:

```text
src/
├── Core/
│   ├── ShNotes.Core/
│   └── ShNotes.UseCases/
│
├── Infra/
│   └── ShNotes.Data/
│
└── Presenters/
    └── ShNotes.WebApi/

tests/
└── ShNotes.Tests/
```

### Core

Содержит основные сущности и абстракции предметной области.

```text
ShNotes.Core
├── Entities
├── Value Objects
└── Domain exceptions
```

Слой не зависит от инфраструктуры или Web API.

### UseCases

Содержит прикладную логику и сценарии использования приложения.

```text
ShNotes.UseCases
└── Notes
    ├── GetNotes
    ├── DTOs
    ├── Profiles
    └── Repository abstractions
```

Для организации use case'ов используется **MediatR**.

Такой подход позволяет отделить прикладную логику от HTTP-слоя и не перегружать контроллеры бизнес-логикой.

### Data

Слой отвечает за работу с базой данных и реализацию инфраструктурных зависимостей.

```text
ShNotes.Data
├── Daos
├── EntityFramework
├── SQL Scripts
└── Dependency Injection
```

Для доступа к данным используется **Entity Framework Core**.

Модели базы данных отделены от доменных сущностей с помощью DAO.

В качестве базы данных на данный момент используется **SQLite**.

### Web API

Слой представления приложения, предоставляющий HTTP API.

```text
ShNotes.WebApi
├── Controllers
├── Middlewares
├── Common
└── Program.cs
```

Контроллеры отвечают преимущественно за обработку HTTP-запросов и передачу управления соответствующим use case'ам.

Для документации и тестирования API используется **Swagger / OpenAPI**.

## API

### Получение заметок

```http
GET /notes
```

Пример запроса с фильтрацией:

```http
GET /notes?name=example
```

Пример ответа:

```json
[
  {
    "id": 1,
    "name": "Example",
    "description": "Example note"
  }
]
```

## Запуск проекта

### Требования

Для запуска необходим:

* [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)
* Git

### Клонирование репозитория

```bash
git clone https://github.com/sh0rtener/notes.git
cd notes
```

### Восстановление зависимостей

```bash
dotnet restore
```

### Сборка

```bash
dotnet build
```

### Запуск

```bash
dotnet run --project src/Presenters/ShNotes.WebApi
```

После запуска API будет доступен по адресу, указанному ASP.NET Core в консоли.

В режиме разработки доступен Swagger UI.
